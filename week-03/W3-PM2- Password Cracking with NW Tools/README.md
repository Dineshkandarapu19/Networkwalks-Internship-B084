
# W3-PM2 – Password Cracking with NetworkWalks Tools

## Cybersecurity & Ethical Hacking Internship

### Project Overview

This project demonstrates password recovery from a password-protected PDF using two free online tools provided by NetworkWalks.

The practical involves extracting the PDF hash using the NetworkWalks Hash Calculator and recovering the password using the NetworkWalks Password Cracker.

## Objective

- Understand how password hashing works.
- Extract a hash from a password-protected PDF.
- Perform password cracking using an online tool.
- Recover the password and verify access to the PDF.

## Lab Environment

| Component | Details |
|---|---|
| Operating System | Windows |
| Platform | Web Browser |
| Target File | My Locked PDF1.pdf |
| Hash Extraction Tool | NetworkWalks Hash Calculator |
| Password Cracking Tool | NetworkWalks Password Cracker |

## Tools Used

1. **NetworkWalks Hash Calculator**  
   https://networkwalks.com/hash-calculator/

2. **NetworkWalks Password Cracker**  
   https://networkwalks.com/password-cracker/

## Practical Implementation

### Step 1 – Download the Encrypted PDF

Downloaded the password-protected PDF file named `My Locked PDF1.pdf` from the provided internship lab page.

### Step 2 – Open Hash Calculator

Opened the NetworkWalks Hash Calculator in a web browser.

### Step 3 – Upload the PDF

Uploaded the encrypted PDF file to extract its password hash.

### Step 4 – Copy the Hash

Copied the complete extracted hash value beginning with `$pdf$`.

### Step 5 – Open Password Cracker

Opened the NetworkWalks Password Cracker in the browser.

### Step 6 – Start Password Cracking

Pasted the extracted PDF hash into the Password Cracker and started the cracking process.

### Step 7 – Recover the Password

Waited for the tool to complete the process and display the recovered password.

### Step 8 – Verify the Password

Opened the protected PDF file and entered the recovered password.

### Step 9 – Confirm the Result

Successfully opened the PDF file, confirming that the password recovery process was completed.

## Final Results

- Successfully extracted the PDF hash.
- Performed password cracking using NetworkWalks tools.
- Recovered the PDF password.
- Verified the recovered password by opening the protected PDF.
